# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

A Claude-powered weekly market intelligence agent for a transformer manufacturing company. Every Monday at 07:30 IST it:
1. Queries a PostgreSQL database (SAP-sourced tables) for sales, production, and vendor data
2. Fetches live commodity prices (Copper LME, Aluminium LME, CRGO Steel, Transformer Oil, HR Steel, USD/INR)
3. Pulls global news events and classifies their impact on transformer raw materials
4. Calls Claude API to generate JSON-structured insights and procurement recommendations
5. Renders a ReportLab PDF (`output/Weekly_Market_Intelligence_Report_{MonDd}_{YYYY}.pdf`)
6. Distributes via SMTP email and/or Slack webhook (only if credentials are non-placeholder)

## Running

```bash
# One-time run
source venv/bin/activate
python main.py

# Scheduled (every Monday 07:30 IST, blocking)
python scheduler.py
```

|---|---|
| `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_SCHEMA` | PostgreSQL connection |

| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `EMAIL_TO` | Email distribution (optional) |
| `SLACK_WEBHOOK` | Slack notification (optional) |
| `TRADING_ECONOMICS_KEY`, `MCX_API_KEY`, `FASTMARKETS_KEY`, `PLATTS_API_KEY`, `GEM_PORTAL_KEY` | Premium market data (optional — fallbacks exist) |

## Architecture

```
main.py                    ← Orchestrator: 9-step pipeline
modules/
  db_connector.py          ← Singleton connection pool (psycopg2), execute_query → list[dict]
  sales_queries.py         ← Weekly/monthly KPIs, date range helpers
  vendor_queries.py        ← Vendor ageing buckets, overdue POs, next-week payments
  market_data.py           ← Commodity price fetchers with fallback prices hardcoded
  events_intel.py          ← NewsAPI fetch + material-impact classification
  analysis.py              ← Price trend analysis, sentiment scores, vendor cross-match
  trend_engine.py          ← Statistical trend direction & sentiment scoring
  prompt_builder.py        ← Assembles structured text prompt from all data
  claude_client.py         ← Claude API call with 3-retry exponential backoff, JSON parse
  charts.py                ← Matplotlib charts → PNG files in output/charts_{date}/
  pdf_generator.py         ← ReportLab PDF assembly; filename: Weekly_Market_Intelligence_Report_{MonDd}_{YYYY}.pdf
  distribution.py          ← Email (smtplib) + Slack webhook; skips silently if not configured
prompts/system_prompt.txt  ← Claude system prompt defining JSON output schema
config/report_config.yaml  ← Company name, currency, thresholds, billing type filters
sql/                       ← Reference SQL for the 4 main DB queries
logs/                      ← Per-run log files + claude_output_{date}.json (audit trail)
output/                    ← Generated PDFs and chart PNGs
```

## Key Data Contracts

**Claude output JSON schema** (defined in `prompts/system_prompt.txt`, parsed in `claude_client.py`):
```json
{
  "executive_summary": ["bullet"],
  "critical_alerts": [{"title": "", "severity": "CRITICAL|HIGH|MEDIUM", "action": ""}],
  "kpi_commentary": "...",
  "production_commentary": "...",
  "customer_commentary": "...",
  "vendor_commentary": "...",
  "market_commentary": "...",
  "recommendations": [{"material": "", "action": "BUY NOW|DEFER|RENEGOTIATE|FORWARD BUY|MONITOR", "rationale": "", "saving_cr": 0.0, "risk_cr": 0.0}],
  "outlook": "..."
}
```

All money values are INR Crores (2 decimal places). Missing data must be stated as "Data unavailable" — never invented.

## Database Tables

- `sales_data` — SAP SD invoices; filtered by `plant`, `billing_type` (F2/ZF2/ZIN, excluding RE/RK returns), `is_transformer = 'Y'`
- `customer_ageing_prod` — Accounts receivable ageing by customer; currency = INR
- `vendor_ageing_prod` — Accounts payable ageing buckets by vendor; currency = INR
- `production_data` — Monthly planned vs achieved production quantities

## Market Data Fallbacks

Every commodity fetcher in `market_data.py` has hardcoded fallback prices used when APIs fail. Update `FALLBACK_PRICES` dict at the top of that file when reference prices become stale.

## PDF Filename Convention

`Weekly_Market_Intelligence_Report_{MonDd}_{YYYY}.pdf` (e.g. `Weekly_Market_Intelligence_Report_Apr18_2026.pdf`). This is generated by `_weekly_report_pdf_basename()` in `pdf_generator.py` from the `dates["today"]` value returned by `get_date_ranges()`.

## Thresholds (config/report_config.yaml)

| Key | Meaning |
|---|---|
| `achievement_critical_pct: 80` | Production <80% → CRITICAL status |
| `po_overpriced_alert_pct: 5` | PO price >5% above market → "OVERPRICED — Renegotiate" |
| `vendor_critical_overdue_days: 90` | Vendor outstanding >90 days → critical |
